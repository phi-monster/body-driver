# 脑到底看不看得见剪刀 —— 离线量的,不连仿真(2026-09-21)

**一句话**:同一个 Qwen3.5-9B,不给任何编号、只给原始灰度帧,问"剪刀在哪",**头顶眼 4/4、腕眼 1/1 框准**;
驱动自己的全局明暗切块在同一把剪刀上是 **4–5 个指甲盖大的碎框**(头顶眼),腕眼清单 **191–450 件**。
⇒ **瞎的不是脑,是"第几号"这个接口。**

做法:箱子空闲时起 `qivllm.sh`(同一个模型、同一个服务),`ground.py` 直接 POST 图 + 一句
`Locate the <名字> … {"found":true,"bbox_2d":[x1,y1,x2,y2]}`,温度 0,关思考。约 **1.7 秒/问**(27 问 45 秒,粗量)。
帧来自今天四炮的原始落盘 `NSC{1..4}/vid/f000000_c{0,1,2}.pgm`(640×480 灰度,无任何叠画)。
回的框是 **0–1000 归一化坐标**(图里红框;蓝框是"当绝对像素读"的错误读法,留着作对照)。

## 这一份【没有】证明的

- **N 小**:5 张干净帧、1 张桌、2 种剪刀落点;全是静帧,**没有闭环**(手进画面、遮挡、运动模糊都没测)。
- **灰度**:落盘只有灰度。彩色只会更容易,但没量。
- "有没有"只有 56% ⇒ 身体**不能**拿脑的 `found:false` 当"桌上没有"的证据;只能当"这只眼里没指出来 ⇒ 换眼再问"。
- 框中心 ≠ 抓取点。剪刀中段窄、两头宽,抓哪儿仍要身体在掩膜上自己挑(接触集那一步,现成)。
