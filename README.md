# body layer — 身体层驱动

> **世界靠学,身体靠量。我一动,跟着动的那一块,就是我。**
> 脑(大模型)只看带编号的画面、只说"第几号 → 去哪 → 直到什么事件为止";身体靠自己动一动把一切量出来;两边之间没有第三种东西。

## 在做什么(边界)
| 学的 | 量的 | 不做 |
|---|---|---|
| 世界:脑在编号彩图上点名(`driver/src/brain.adb` 合同,`问脑` 同款) | 部件图(逐通道推)· 相机长在哪只手 · 握区(合空扫过的像素)· 通道响应表(递推最小二乘)· 噪声地板 · 碰上/推不动(零表更准)· 拿住了没(抬一截看跟不跟) | 机体参数 / URDF / 相机内外参 / 写死的策略 / 标定文件装回 / 真机 / 力的大小(只当机体自报的数据) |

驱动 = `driver/`(Ada;监视器 `monitor` 与备份 `backup` 是 SPARK,gnatprove 34 条全证;其余 Ada 加运行时检查)。零依赖(msgpack、WebSocket、HTTP、JSON、BMP、光流全自写)。安全核 `fast/`(SPARK,40/40)沿用。
