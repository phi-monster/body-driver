# body layer — 身体层驱动

> **世界靠学,身体靠量。我一动,跟着动的那一块,就是我。手在哪,靠感觉不靠认:关节这样的时候手在画面哪儿,看过一次就记住。**
> 脑(大模型)只看带编号的画面、只说"第几号 → 去哪 → 直到什么事件为止";身体靠自己动一动把一切量出来;两边之间没有第三种东西。

## 在做什么(边界)
| 学的 | 量的 | 不做 |
|---|---|---|
| 世界:脑在编号彩图上点名(`driver/src/brain.adb` 合同,`问脑` 同款) | 部件图(逐通道推)· 相机长在哪只手 · 握区(合空扫过的像素)· 通道响应表(递推最小二乘)· 噪声地板 · 碰上/推不动(零表更准)· 拿住了没(抬一截看跟不跟) | 机体参数 / URDF / 相机内外参 / 写死的策略 / 真机 / 力的大小(只当机体自报的数据) |

驱动 = `driver/`(Ada;监视器 `monitor` 与备份 `backup` 是 SPARK,gnatprove 34 条全证;其余 Ada 加运行时检查)。零依赖(msgpack、WebSocket、HTTP、JSON、BMP、光流全自写)。安全核 `fast/`(SPARK,40/40)沿用。
**身体图**(`schema`,owner 2026-09-07:"人永远不需要认出自己的手"):每次真看见自己手指(合手/抖手指时动过的像素)就把 位姿 → 两瓣位置+深度 记成样本;之后手在世界相机里的位置 = 按此刻位姿查最近样本 + 响应表外推,**不看画面**;熟地(离样本不超过一步核实过的步幅)只让光流核对,生地或大步才抖手指看一眼、看完记进图。存进身体文件。
**全身,只有一种东西:零件**(owner 2026-09-07:"必须加了全身""手指不也是零件吗"):每个通道带一块 —— 那个通道单独动时跟着动的那一块(从那个关节往外);握合通道也是通道,它带的那块就是手指(`Chan_K = Chan.Per_Arm`),多团时每团一个点(两指 = 2 团;五指是欠账)。开机每个通道推过一下、合空一次,就把全部零件记进同一位姿的样本;脑能点名任何一块并让它去某格/某关系,身体缺表当场量表;生地/大步后"看一眼" = 推一下它自己的通道再推回(手指就是合几拍再张回),动过的像素就是它。
**越用越强 = 身体文件**(`--in/--out cal.json`,钥匙 = 机体自报的形状):开机装回 → 每只手推一下核对 → 同一具身体直接用(探针 300 拍 → 核对 ~20 拍);对不上才重量;历次量到的取中位数、噪声地板只放大;响应表和核实过的步幅一起存。
